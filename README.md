# 🔢 7-Segment Playground

A collection of Arduino projects built around one of the most useful and classic display components: the 7-segment display.

This repository explores different ways to control 7-segment displays, from simple number displays and counters to more advanced concepts such as multiplexing, timing with `millis()`, lookup tables, state machines and non-blocking programming.

The goal is not only to learn how to display numbers, but also to understand the underlying logic of display control and build a stronger foundation in embedded systems development.

P.S) Seven segments, seen and used all around you in real life :)

---

## 📚 Concepts Covered

* Digital Output
* Digital Input (Buttons)
* 7-Segment Display Control
* Digit & Segment Mapping
* Lookup Tables
* Number Representation
* Counters
* Multiplexing
* Timing with `millis()`
* Non-blocking Programming
* State Machines
* Finite State Machines (FSM)
* Random Number Generation
* Modular Programming
* Embedded Software Design

## 🎯 Purpose

This repository documents my journey of learning embedded systems through small, focused Arduino projects using 7-segment displays.
Instead of building only large projects, this collection explores different aspects of display control one concept at a time. Each project introduces a new programming technique while keeping the hardware relatively simple.
